# Security policy

Please report security problems privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private advisory), and do not post details in a public issue.
Loud runs as your normal user, installs without administrator rights, and has no network code, so the most useful reports are about the installer and uninstaller scripts (what they delete or write), the release zip, and the workflow in `.github/workflows`. I will answer as soon as I can.
